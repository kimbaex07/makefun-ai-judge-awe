One short text (194 characters) written to slow its reader down: the
tide coming in whether or not anyone is watching, smoothing the sand,
erasing the footprints, leaving the beach new again.

## The text

> The tide comes in whether or not anyone is watching. It smooths
> the sand, erases the footprints, and leaves the beach new again.
> Nothing to fix. Nothing to hold. Only slow water, doing its work.

Why this scene: it shows instead of instructing, it is plain and
concrete, and the tide is an image that keeps growing after the last
line — water that has done this forever and will keep doing it. It
was written against the judge's brief: relax first, show rather
than tell, plain gentle words, one thought that dwarfs the reader,
and a voice of its own rather than a familiar meditation script.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (194 characters, UTF-8) to
`$MAKEFUN_OUTPUT_DIR`, byte for byte the same on every run. Python
3.13, standard library only, no network.
